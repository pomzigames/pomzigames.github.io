# RadyoBox katalogları

`stations.json` ve `podcasts.json`, RadyoBox uygulamasının HTTPS üzerinden güncellediği herkese açık kataloglardır. Uygulama ağ hatasında kendi içindeki güvenli katalog kopyasını kullanır.

Yeni sürüm yayımlarken `revision` değerini artırın; akış ve RSS adreslerini doğrudan medya içeriğiyle doğrulayın. Geçici olarak çalışmayan istasyonlar `enabled: false` olarak tutulur.
